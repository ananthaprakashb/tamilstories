# திருக்குறள் கதைகள்

Canonical story source for the ShareCapsule `/tamilbooks/` reader.

## Reader contract

- `book.json` provides book-level metadata and cover artwork.
- Chapter Markdown remains the canonical manuscript.
- Chapter front matter provides cinematic reader metadata such as `title`, `subtitle`, `mood`, `scene`, and `artwork`.
- The ShareCapsule reader auto-discovers chapter Markdown files in this folder from the Stories repository.
- Ambient audio is intentionally omitted for now; the reader treats it as optional and opt-in.
